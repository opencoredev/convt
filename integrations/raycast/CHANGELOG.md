# Convt Changelog

## [Folders, Presets, and More Options] - {PR_MERGE_DATE}

- Convert folders, optionally including subfolders. Output formats come from the files inside, and files that can't convert are skipped. A folder with nothing to convert is listed as skipped in the results.
- Choose a saved Convt preset.
- Set a background for transparent areas in image outputs.
- Set a maximum video height, the video codec (H.264 or HEVC), the audio bitrate, or remove audio from videos.
- Set how many files convert at once with the Parallel Conversions preference.
- Install Convt's document pack from the command when Office documents can't convert.
- Raycast AI can convert folders, use presets and the new options, and explains when the document pack is missing.
- Requires Convt 0.5.0 or newer.

## Suggested Output Formats - 2026-10-15

- Show file types identified from filename extensions before choosing an output format.
- Suggest common output formats using Convt's recommendations while keeping all supported formats available.
- Keep your chosen output when it remains supported and refresh suggestions when files change.
- Identify file types and suggest output formats with Raycast AI.

## Initial Version - 2026-10-13

- Convert local images, videos, audio, PDFs, and documents with Convt.
- Use selected Finder files or choose multiple files in Raycast.
- Discover available formats and customize output folders, quality, image size, and PDF rendering.
- View conversion progress, cancel batches, and open or copy completed files.
- Discover formats and convert files with Raycast AI.
