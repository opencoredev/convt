---
title: Base URL
description: The host every convt API request goes to, and a free connectivity check.
---

Send every request to:

```
{{api}}
```

All routes are versioned under `/v1`. Keep the host in one setting so tests can point at a mock:

```bash
export CONVT_API={{api}}
```

`GET /health` returns `ok` and needs no key, which makes it a cheap connectivity check:

```bash
curl {{api}}/health
```

`GET /v1/formats` also needs no key. It lists every format id you can pass as `from` or `to`.
