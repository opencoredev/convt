| Host      | Status                                      |
| --------- | ------------------------------------------- |
| `{{api}}` | **Live.** Use this for production requests. |

Every example on this site uses the canonical production host. The Railway hostname remains available as an operational fallback. Paths, keys, request bodies and responses are the same on both.

Keep the host in one setting:

```bash
export CONVT_API={{api}}
```

All routes are versioned under `/v1`. `GET /health` returns `ok` and needs no key, which makes it a cheap connectivity check:

```bash
curl {{api}}/health
```
