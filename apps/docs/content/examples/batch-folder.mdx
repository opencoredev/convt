---
title: Convert a folder
description: Convert every file in a folder through the API while staying under the rate limit.
---

`batch.mjs` converts every file in a folder, a few at a time. It imports `convertFile` from the [Node helper](/examples/node-script).

```js batch.mjs lineNumbers
import { readdir } from "node:fs/promises";
import { join } from "node:path";
import { convertFile } from "./convt.mjs";

const [dir, to, concurrency = "4"] = process.argv.slice(2);
const workers = Number(concurrency);
if (!Number.isInteger(workers) || workers < 1)
  throw new Error("concurrency must be a positive integer");
// Poll each job every `workers` seconds so concurrent polls stay near 1/s.
// create, start, download and retries are paced in convt.mjs.
const pollMs = workers * 1000;
const files = (await readdir(dir, { withFileTypes: true }))
  .filter((entry) => entry.isFile())
  .map((entry) => join(dir, entry.name));

let next = 0;
let failed = 0;
async function worker() {
  while (next < files.length) {
    const file = files[next++];
    try {
      const saved = await convertFile(file, to, { pollMs });
      console.log(`${file} -> ${saved.join(", ")}`);
    } catch (error) {
      failed++;
      console.error(`${file}: ${error.message}`);
    }
  }
}

await Promise.all(Array.from({ length: workers }, worker));
console.log(`${files.length - failed} converted, ${failed} failed`);
process.exitCode = failed ? 1 : 0;
```

```console
$ node batch.mjs ./photos webp 4
photos/a.png -> a.webp
photos/b.heic -> b.webp
2 converted, 0 failed
```

## Stay under the rate limit

Your key gets 120 requests a minute, or 2 a second. The [Node helper](/examples/node-script) puts every create, start, poll, download, cancel and retry through one shared queue, so a folder of small files cannot burst past that limit. This script also polls each job every N seconds when it runs N at a time, so polling does not crowd out the other calls. Raising the concurrency speeds up the folder but makes each job's result arrive a little later.

Two files with the same name and different extensions, such as `a.png` and `a.heic`, both save as `a.webp`. Convert them into separate folders if that matters.

For folders on your own machine, the [convt CLI](https://convt.app/download) does the same thing locally, with no key and no upload:

```bash
convt ./photos -r --to webp -j 4
```
