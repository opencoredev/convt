# convt brand kit

The convt logo, wordmark, colors and type. Every file is free to use when writing about convt or linking to it.

## Logos

Each logo comes as SVG and PNG. "white" versions are for dark backgrounds, "black" versions for light ones.

- [Everything as a ZIP](https://convt.app/brand/convt-brand.zip)
- Mark (green, any background): [SVG](https://convt.app/brand/convt-mark.svg), [PNG](https://convt.app/brand/convt-mark.png)
- Lockup, mark and name: [white SVG](https://convt.app/brand/convt-lockup-white.svg), [black SVG](https://convt.app/brand/convt-lockup-black.svg), [white PNG](https://convt.app/brand/convt-lockup-white.png), [black PNG](https://convt.app/brand/convt-lockup-black.png)
- Wordmark: [white SVG](https://convt.app/brand/convt-wordmark-white.svg), [black SVG](https://convt.app/brand/convt-wordmark-black.svg), [white PNG](https://convt.app/brand/convt-wordmark-white.png), [black PNG](https://convt.app/brand/convt-wordmark-black.png)
- One-color mark: [white SVG](https://convt.app/brand/convt-mark-white.svg), [black SVG](https://convt.app/brand/convt-mark-black.svg), [white PNG](https://convt.app/brand/convt-mark-white.png), [black PNG](https://convt.app/brand/convt-mark-black.png)

## Colors

- Green `#2FBF78` and Deep green `#1F9A5C`: the mark's gradient, top to bottom
- Signal `#3FCB84`: green text on dark
- Forest `#127A47`: green text on light
- Ink `#0A0B0B`, Graphite `#111312`, Line `#232726`, Paper `#EDEFEE`: neutrals

## Type

Geist for text and the wordmark (SemiBold), Geist Mono for file names and commands. Both are free from [vercel.com/font](https://vercel.com/font).

## Usage

- Write the name lowercase: convt, even at the start of a sentence.
- Keep clear space of a quarter of the mark's width around it, and set the mark at 16 px or larger.
- Don't recolor, stretch, rotate or add effects to the logo. Use the version made for your background.
