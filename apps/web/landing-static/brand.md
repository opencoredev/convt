# convt brand kit

The convt logo, wordmark, colors and type. Every file is free to use when writing about convt or linking to it.

The mark is two overlapping rounded squares: the file you have (ink) and the file you get (green). The overlap, in a third shade, is where the conversion happens.

## Logos

Each logo comes as SVG and PNG. "on-dark" versions are for dark backgrounds, "on-light" versions for light ones.

## Colors

On dark backgrounds (page `#0A0B0B`):

- Ink `#EDEFEE`: source square and wordmark
- Green `#46D08B` to Deep green `#1FA463`: converted square, top to bottom
- Overlap `#A6F0C8`

On light backgrounds (page `#FFFFFF`):

- Ink `#0A0A0A`: source square and wordmark
- Green `#1FB36C` to Deep green `#127A47`: converted square, top to bottom
- Overlap `#0B5C34`

## Type

Geist for text and the wordmark (SemiBold, -0.02em tracking), Geist Mono for file names and commands. Both are free from [vercel.com/font](https://vercel.com/font).

## Usage

- Write the name lowercase: convt, even at the start of a sentence.
- Keep clear space at least as wide as the overlap square around the logo, and set the mark at 16 px or larger.
- Don't recolor, stretch, flip or add effects to the logo. Use the version made for your background.
