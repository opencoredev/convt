# convt: convert any file with a right-click

Images, video, audio and documents, converted on your own computer. Nothing gets uploaded.

convt is coming soon to macOS, Windows and Linux. There is no download, account or checkout yet.

## How it works

Right-click a file in Finder or your Linux file manager, pick a format, and convt writes the converted file next to the original. Explorer on Windows is to follow. The same conversions run from the `convt` command line tool, which also converts whole folders, and the desktop app.

## Formats

40 formats in one menu:

- **Images (14):** JPG, PNG, WebP, HEIC, AVIF, GIF, TIFF, BMP, ICO, TGA, PPM, QOI, EXR, SVG
- **Video (5):** MP4, MOV, WebM, MKV, AVI
- **Audio (7):** MP3, WAV, FLAC, AAC, M4A, OGG, Opus
- **Documents (14):** PDF, DOCX, DOC, ODT, RTF, TXT, HTML, PPTX, PPT, ODP, XLSX, XLS, ODS, CSV

## Engines

convt drives established open source tools from Rust, on your machine:

- **FFmpeg** for video and audio.
- **LibreOffice** for Word, Excel and PowerPoint files and their open formats, and for saving any of them as PDF.
- **PDFium**, the PDF renderer inside Chrome, to turn PDF pages into images.
- **image and resvg**, pure Rust decoders for photos and a Rust SVG renderer.
